# 🔍 ReFinder — Lost & Found Community Platform

ReFinder is a full-stack Lost & Found community platform designed to help people reconnect with their lost belongings through a secure and community-driven verification system.

Users can upload details of lost or found items, while administrators verify submissions before publishing them publicly to ensure authenticity and trust within the platform.

# ✨ Features

## 📦 Lost & Found Management

- Report Lost Items
- Upload Found Items
- Browse Community Listings
- Search Available Posts
- Upload Item Images

---

## ✅ Admin Verification System

Every submitted item goes through an Admin Approval Workflow.

### Workflow:

1. User submits lost/found item
2. Request goes to Admin Panel
3. Admin reviews submission
4. Approved items are published publicly

This helps maintain:

- Platform Authenticity
- Spam Prevention
- Trusted Community Listings

---

## 🛠️ Admin Dashboard

Dedicated Admin Panel for:

- Reviewing User Requests

- Managing Community Posts
- Monitoring Platform Activity

# ⚙️ Installation Guide

## 1️⃣ Clone Repository

```bash
git clone https://github.com/yugtasaini624/ReFinder---Lost-Found-Community-Application
```

---

## 2️⃣ Open Project Folder

```bash
cd ReFinder
```

---

# 📂 Project Structure

The repository contains:

- frontend
- backend
- admin-panel

---

## 3️⃣ Frontend Setup

```bash
cd frontend

npm install

npm start
```

---

## 4️⃣ Backend Setup

```bash
cd backend

pip install -r requirements.txt

python run.py
```

---

## 5️⃣ Admin Panel Setup

```bash
cd admin-panel

npm install

npm start
```
